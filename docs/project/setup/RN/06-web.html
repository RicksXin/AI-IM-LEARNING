Step 6

在 Web 平台运行 React Native 项目

推荐：Expo Web 底层：React Native Web 返回目录

最快方式：Expo

cd D:\Developer\Project\Personal\LearningAI
npx create-expo-app RNWebDemo
cd RNWebDemo
npx expo start --web

浏览器会打开本地页面。如果没有自动打开，按终端提示访问本地地址。

已有 Expo 项目

cd RNWebDemo
npx expo install react-dom react-native-web @expo/metro-runtime
npx expo start --web

已有裸 RN 项目

裸 RN 项目也能接 React Native Web，但配置会更复杂。初学阶段建议单独用 Expo 验证 Web 页面，等页面结构稳定后再统一工程。

npm install react-dom react-native-web

注意事项

  • 不是所有原生组件都能无损运行到 Web。
  • 文件选择、通知、拖拽、键盘快捷键通常要写 Web 专属逻辑。
  • IM 项目的 Web 端更像桌面网页，布局和移动端可以共享业务逻辑，但不必强求完全同 UI。
