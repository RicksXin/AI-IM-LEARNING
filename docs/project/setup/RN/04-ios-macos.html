Step 4

在 iOS / macOS 平台运行 React Native 项目

必须使用 macOS iOS：Xcode + CocoaPods 返回目录

运行到 iOS 模拟器

cd RNDemo
cd ios
pod install
cd ..
npm run ios

如果你想指定模拟器：

npx react-native run-ios --simulator "iPhone 16"

运行到 iPhone 真机

  1. 用 USB 连接 iPhone。
  2. 打开 ios/RNDemo.xcworkspace。
  3. 在 Xcode 中选择你的真机。
  4. 设置 Apple Developer Team。
  5. 点击 Run。
新手建议：先跑模拟器，真机签名失败是常见问题，不要一开始就卡在证书上。

运行到 macOS 桌面

React Native macOS 是 Microsoft 维护的桌面端适配。桌面端版本可能落后于 React Native 核心版本，创建前先查看官方版本表。

cd RNDemo
npx react-native-macos-init
npx react-native run-macos

常见问题

问题 处理
pod install 失败 确认 CocoaPods 已安装，必要时运行 pod repo update。
Xcode 命令行工具异常 运行 sudo xcode-select -s /Applications/Xcode.app。
真机签名失败 在 Xcode 的 Signing & Capabilities 里选择开发团队。
