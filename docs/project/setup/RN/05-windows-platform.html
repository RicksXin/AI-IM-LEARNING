Step 5

在 Windows 平台运行 React Native 项目

目标：Windows 桌面应用 技术：React Native Windows 返回目录

先理解边界

React Native Windows 是桌面端适配，不是 Android 的替代品。它需要 Visual Studio、Windows SDK 和 C++ 构建工具。桌面端版本可能落后于 RN 核心版本，按官方文档选择匹配版本。

安装依赖

推荐用官方依赖脚本检查和安装。用管理员 PowerShell 执行：

npx react-native-windows-init --help
npx @react-native-windows/cli@latest init-windows --help

同时确认已安装：

  • Visual Studio 2022
  • Desktop development with C++ 工作负载
  • Windows 10/11 SDK
  • Node.js 22.11+

给已有 RN 项目加 Windows

cd RNDemo
npx @react-native-windows/cli@latest init-windows --overwrite
npx react-native run-windows

如果你使用旧版 RNW 文档，可能会看到 npx react-native-windows-init --overwrite。新项目优先按官方当前文档使用 init-windows。

如果命令提示版本不匹配，按提示安装对应版本的 react-native-windows。

常见问题

问题 处理
找不到 MSBuild 安装 Visual Studio 2022 和 C++ 工作负载。
RNW 版本不兼容 查看 React Native Windows 官方版本矩阵。
首次构建很慢 正常现象，Windows 原生构建依赖较多。
