Step 7

在 HarmonyOS 平台运行 React Native 项目

目标：HarmonyOS / OpenHarmony 工具：DevEco Studio 返回目录

先理解成熟度

HarmonyOS 不是 React Native 官方核心平台，通常需要使用 OpenHarmony SIG 的 ohos_react_native 或相关 React Native OpenHarmony 适配。它更适合单独验证，不建议和 Android/iOS 在第一天强行合并交付。

新手建议：先跑通 Android，再单独开一个 HarmonyOS 分支或示例项目验证。

需要安装什么

  • Node.js 22.11+。
  • Git。
  • DevEco Studio。
  • HarmonyOS / OpenHarmony SDK。
  • OpenHarmony SIG 的 React Native 适配库。

推荐流程

  1. 安装 DevEco Studio。
  2. 在 DevEco Studio 中安装 HarmonyOS SDK。
  3. 准备模拟器或真机，并确认设备能被 DevEco Studio 识别。
  4. 阅读 ohos_react_native 仓库 README。
  5. 按仓库提供的模板创建或改造 RN 工程。
  6. 用 DevEco Studio 打开 HarmonyOS 工程并运行。

示意命令

不同版本的命令可能变化，以 OpenHarmony SIG 仓库为准。下面只作为流程感知：

node -v
npm -v
git --version

# 克隆官方适配仓库，查看 README 和示例
git clone https://gitee.com/openharmony-sig/ohos_react_native.git

常见问题

问题 处理
命令和教程对不上 HarmonyOS 适配变化较快，以仓库 README 和分支说明为准。
设备运行失败 先确认 DevEco Studio 能独立运行一个空 HarmonyOS 项目。
三方 RN 库不可用 优先检查该库是否支持 HarmonyOS，原生模块通常要适配。
