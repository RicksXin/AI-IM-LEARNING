Step 2

macOS / Linux 系统中安装和配置 React Native

macOS：Android + iOS Linux：Android + Web 返回目录

macOS 基础安装

xcode-select --install

brew install node watchman
brew install --cask zulu@17
brew install cocoapods

检查版本：

node -v
npm -v
java -version
pod --version
iOS 必需：打开 App Store 安装 Xcode，然后打开一次 Xcode，接受许可并安装组件。

Linux 基础安装

以 Ubuntu 为例。Linux 不能构建 iOS，只建议跑 Android 和 Web。

sudo apt update
sudo apt install -y curl git unzip openjdk-17-jdk

curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install --lts
nvm use --lts

Android SDK 环境变量

安装 Android Studio 后，把下面内容加入 ~/.zshrc 或 ~/.bashrc。

# macOS
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"

# Linux 常见路径
export ANDROID_HOME="$HOME/Android/Sdk"
export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"

重新打开终端后检查：

adb version
emulator -version

创建项目

npx @react-native-community/cli@latest init RNDemo
cd RNDemo
npx react-native doctor
