React Native Setup

React Native 开发环境搭建教程

面向初学者 Windows / macOS / Linux Android / iOS / Windows / Web / HarmonyOS 更新日期：2026-05-17

怎么读

先按你的电脑系统完成基础环境，再按目标平台运行项目。初学阶段推荐先跑通 Android 或 Web，再挑战 iOS、Windows 桌面和 HarmonyOS。

工具链提醒：React Native 官方当前要求 Node 22.11+；Android 原生构建推荐 JDK 17；iOS 构建必须使用 macOS + Xcode。

教程列表

1. Windows 系统中安装和配置 RN

适合你当前 Windows 电脑。包含 winget、Node、JDK、Android Studio、环境变量。

2. macOS / Linux 系统中安装和配置 RN

macOS 可跑 Android 和 iOS；Linux 通常只跑 Android 和 Web。

3. 在 Android 平台运行 RN 项目

创建项目、启动 Metro、打开模拟器、运行到 Android。

4. 在 iOS / macOS 平台运行 RN 项目

iOS 真机/模拟器、CocoaPods、以及 React Native macOS 桌面端。

5. 在 Windows 平台运行 RN 项目

React Native Windows，适合做 Windows 桌面应用。

6. 在 Web 平台运行 RN 项目

推荐使用 Expo / React Native Web 快速跑 Web。

7. 在 HarmonyOS 平台运行 RN 项目

使用 OpenHarmony SIG / React Native OpenHarmony 生态，适合单独验证。

推荐路线

  1. Windows 用户：读 1 和 3，先跑 Android。
  2. macOS 用户：读 2、3、4，可以跑 Android 和 iOS。
  3. 想快速看页面：读 6，先跑 Web。
  4. 想做桌面端：Windows 读 5，macOS 读 4。
  5. 想做 HarmonyOS：读 7，单独准备 DevEco Studio 和 HarmonyOS SDK。
