Step 3

在 Android 平台运行 React Native 项目

适合：Windows / macOS / Linux 目标：Android 模拟器或真机 返回目录

准备模拟器

  1. 打开 Android Studio。
  2. 打开 Device Manager。
  3. 创建一个 Pixel 设备。
  4. 选择一个已安装的 Android System Image。
  5. 启动模拟器。
adb devices

能看到设备列表，说明模拟器或真机已连接。

运行项目

cd D:\Developer\Project\Personal\LearningAI\RNDemo
npm start

另开一个终端：

cd D:\Developer\Project\Personal\LearningAI\RNDemo
npm run android

真机调试

  1. 手机打开开发者选项。
  2. 开启 USB 调试。
  3. 用 USB 连接电脑，允许调试授权。
  4. 运行 adb devices 确认设备状态是 device。
adb devices
npm run android

常见问题

问题 处理
找不到 SDK 检查 ANDROID_HOME 和 platform-tools 是否在 PATH。
Gradle 下载慢 保持网络稳定，第一次构建通常较慢。
模拟器黑屏或慢 开启硬件虚拟化，或用真机调试。
