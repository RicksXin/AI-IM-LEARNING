Step 1

Windows 系统中安装和配置 React Native

适合：Windows 10/11 64 位 目标：Android / Web / Windows 桌面 返回目录

需要安装什么

工具 作用 建议
Node.js 运行 Metro、安装 npm 依赖。 Node 22.11+。
JDK 17 Android 构建需要 Java。 Microsoft OpenJDK 17。
Android Studio 安装 Android SDK、模拟器。 安装 Android SDK Platform 和 Emulator。
Git / VS Code 代码管理和编辑器。 你当前机器已安装。

一键安装基础工具

用 PowerShell 执行。Android Studio 安装后还需要手动打开一次，安装 SDK。

winget install OpenJS.NodeJS.LTS -e
winget install Microsoft.OpenJDK.17 -e
winget install Google.AndroidStudio -e
winget install Git.Git -e
winget install Microsoft.VisualStudioCode -e

安装后关闭 PowerShell，重新打开，再检查：

node -v
npm -v
java -version
git --version

配置 Android SDK 环境变量

Android Studio 默认 SDK 路径通常是 %LOCALAPPDATA%\Android\Sdk。

$androidHome = "$env:LOCALAPPDATA\Android\Sdk"
[Environment]::SetEnvironmentVariable("ANDROID_HOME", $androidHome, "User")

$paths = @(
  "$androidHome\platform-tools",
  "$androidHome\emulator",
  "$androidHome\cmdline-tools\latest\bin"
)

$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
foreach ($path in $paths) {
  if ($userPath -notlike "*$path*") {
    $userPath = "$userPath;$path"
  }
}
[Environment]::SetEnvironmentVariable("Path", $userPath, "User")

重新打开 PowerShell 后检查：

adb version
emulator -version

创建 RN 项目

cd D:\Developer\Project\Personal\LearningAI
npx @react-native-community/cli@latest init RNDemo

如果安装依赖很慢，可以临时切换 npm 镜像：

npm config set registry https://registry.npmmirror.com

常见检查

cd RNDemo
npx react-native doctor

看到 Android SDK 或 JDK 报错时，优先回到 Android Studio 的 SDK Manager 检查 SDK 是否安装完整。
