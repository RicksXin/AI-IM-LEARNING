本文档按当前机器环境编写：Windows 11 家庭中文版 64 位，PowerShell 7.6.1；已检测到 winget、Git 和 VS Code，未检测到 go 命令。因此，推荐使用 Windows 包管理器 winget 自动安装 Go。

方式一：winget 自动安装

这是当前机器的推荐方式。脚本会检查 winget，安装官方 Go 包 GoLang.Go，刷新当前终端的 PATH，并把用户级 Go 工具目录 %USERPROFILE%\go\bin 加入用户环境变量。

执行前注意：如果你已经手动安装过 Go，建议先运行 go version 看看版本。重复安装通常会升级或修复，但初学阶段保持一个安装来源最省心。 
$ErrorActionPreference = "Stop"

function Add-UserPathIfMissing {
  param([Parameter(Mandatory = $true)][string]$PathToAdd)

  $current = [Environment]::GetEnvironmentVariable("Path", "User")
  $parts = @()
  if ($current) {
    $parts = $current -split ";" | Where-Object { $_ -and $_.Trim() }
  }

  $exists = $parts | Where-Object { $_.TrimEnd("\") -ieq $PathToAdd.TrimEnd("\") }
  if (-not $exists) {
    $next = (@($parts) + $PathToAdd) -join ";"
    [Environment]::SetEnvironmentVariable("Path", $next, "User")
    Write-Host "已加入用户 PATH: $PathToAdd"
  } else {
    Write-Host "用户 PATH 已包含: $PathToAdd"
  }
}

if (-not (Get-Command winget -ErrorAction SilentlyContinue)) {
  throw "未找到 winget。请先从 Microsoft Store 更新“应用安装程序”，或使用本文的 MSI 安装方式。"
}

winget install --id GoLang.Go -e --source winget `
  --accept-source-agreements `
  --accept-package-agreements

$goBin = "C:\Program Files\Go\bin"
$userGoBin = Join-Path $env:USERPROFILE "go\bin"
Add-UserPathIfMissing -PathToAdd $goBin
Add-UserPathIfMissing -PathToAdd $userGoBin

$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" +
            [Environment]::GetEnvironmentVariable("Path", "User")

go version
go env GOPATH GOROOT GOOS GOARCH

如果最后输出类似 go version go1.26.3 windows/amd64，说明安装成功。版本号会随着 Go 官方发布和 winget 源更新而变化。

方式二：官方 MSI 兜底安装

如果 winget 不可用，可以从 Go 官方下载最新稳定版 Windows amd64 MSI。下面脚本会访问 Go 官方下载接口，自动选择最新稳定版 Windows 64 位安装包并启动安装。 

$ErrorActionPreference = "Stop"

$releases = Invoke-RestMethod -Uri "https://go.dev/dl/?mode=json"
$release = $releases | Select-Object -First 1
$file = $release.files |
  Where-Object { $_.os -eq "windows" -and $_.arch -eq "amd64" -and $_.kind -eq "installer" } |
  Select-Object -First 1

if (-not $file) {
  throw "未在 Go 官方下载列表中找到 Windows amd64 MSI 安装包。"
}

$url = "https://go.dev/dl/$($file.filename)"
$installer = Join-Path $env:TEMP $file.filename

Write-Host "正在下载: $url"
Invoke-WebRequest -Uri $url -OutFile $installer

Write-Host "正在启动安装器: $installer"
Start-Process msiexec.exe -Wait -ArgumentList "/i `"$installer`""

$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" +
            [Environment]::GetEnvironmentVariable("Path", "User")

go version

MSI 安装后通常会把 C:\Program Files\Go\bin 写入系统 PATH。如果当前终端还找不到 go，关闭 PowerShell 后重新打开即可。

安装 VS Code Go 插件

当前机器已检测到 VS Code。安装 Go 插件后，VS Code 会提供语法高亮、跳转、格式化、调试和测试入口。 

if (Get-Command code -ErrorAction SilentlyContinue) {
  code --install-extension golang.go
} else {
  Write-Host "未找到 code 命令。可以打开 VS Code，在扩展市场搜索 Go 并安装官方 Go 插件。"
}

第一次打开 Go 文件时，VS Code 可能提示安装 gopls、dlv 等工具。按提示安装即可；这些工具通常会安装到 %USERPROFILE%\go\bin。

可选：配置 Go 模块代理

如果下载依赖很慢，可以配置 Go 模块代理。公司或团队有统一代理时，应优先使用团队指定配置。 

# 中国大陆网络常用配置
go env -w GOPROXY=https://goproxy.cn,direct

# 如需恢复 Go 官方默认代理
go env -w GOPROXY=https://proxy.golang.org,direct

查看当前配置： 

go env GOPROXY GOPATH GOROOT GOBIN

创建第一个 Go 项目

Go 现在以模块为基本单位。初学时可以把练习项目放到用户目录下，例如 $HOME\go-practice\hello-go。 

$project = Join-Path $HOME "go-practice\hello-go"
New-Item -ItemType Directory -Force $project | Out-Null
Set-Location $project

go mod init example.com/hello-go

@'
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go on Windows!")
}
'@ | Set-Content -Path .\main.go -Encoding UTF8

go fmt .\main.go
go run .

看到 Hello, Go on Windows! 就说明开发环境已经能正常编译和运行 Go 程序。

再加一个测试

Go 自带测试工具，初学者应该尽早习惯 go test。 

@'
package main

func Add(a int, b int) int {
    return a + b
}
'@ | Set-Content -Path .\add.go -Encoding UTF8

@'
package main

import "testing"

func TestAdd(t *testing.T) {
    got := Add(2, 3)
    want := 5
    if got != want {
        t.Fatalf("Add(2, 3) = %d, want %d", got, want)
    }
}
'@ | Set-Content -Path .\add_test.go -Encoding UTF8

go fmt .\add.go .\add_test.go
go test ./...

如果输出 ok，说明测试通过。

日常常用命令

命令 用途
go version 查看 Go 是否安装成功，以及当前版本。
go env 查看 Go 环境变量，例如 GOPATH、GOROOT、GOPROXY。
go mod init example.com/app 初始化一个 Go 模块。
go run . 编译并运行当前目录的程序。
go test ./... 运行当前模块下所有测试。
go fmt ./... 格式化当前模块下的 Go 代码。
go mod tidy 整理依赖，添加缺失依赖并删除不再使用的依赖。
go install package@latest 安装 Go 编写的命令行工具到 %USERPROFILE%\go\bin。

常见问题

PowerShell 提示 go 不是内部或外部命令

通常是当前终端还没有加载新的 PATH。先运行： 

$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" +
            [Environment]::GetEnvironmentVariable("Path", "User")
go version

如果仍然失败，关闭 PowerShell 和 VS Code 终端，重新打开后再试。

VS Code 能打开文件，但没有补全和跳转

确认已安装官方 Go 插件，并允许它安装 gopls。也可以在终端运行： 

go install golang.org/x/tools/gopls@latest

下载依赖失败或很慢

先检查网络，然后查看 GOPROXY： 

go env GOPROXY

如在中国大陆网络环境，可以尝试本文的模块代理配置。

GOROOT 和 GOPATH 要手动设置吗

初学者通常不需要手动设置。GOROOT 是 Go 安装目录，MSI 会处理；GOPATH 默认是 %USERPROFILE%\go。现在 Go 项目主要依赖 go.mod 管理，不需要把项目放进 GOPATH。

卸载或升级

如果使用 winget 安装，可以用以下命令升级或卸载： 

# 升级 Go
winget upgrade --id GoLang.Go -e --source winget

# 卸载 Go
winget uninstall --id GoLang.Go -e
谨慎删除：%USERPROFILE%\go 里可能有你安装的工具和缓存。卸载 Go 不一定需要删除这个目录，除非你明确知道里面没有要保留的内容。
