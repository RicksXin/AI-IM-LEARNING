macOS 初学者 Go 环境安装指南

生成日期：2026-05-18 当前系统：macOS 26.2 CPU 架构：x86_64 Shell：zsh 推荐安装器：Homebrew

当前环境结论

本文档按当前机器环境编写：macOS 26.2，Intel 架构 x86_64，默认 Shell 是 zsh；已检测到 Homebrew 5.1.11，安装路径为 /usr/local，未检测到 go 命令。因此，推荐使用 Homebrew 自动安装 Go。

项目 检测结果 说明
操作系统 macOS 26.2 适合安装官方 macOS pkg 或 Homebrew 版本 Go。
CPU 架构 x86_64 当前机器是 Intel Mac；官方 pkg 应选择 macOS x86-64 版本。Apple Silicon Mac 应选择 ARM64 版本。
Homebrew 已安装：5.1.11 当前前缀是 /usr/local。Apple Silicon 常见前缀是 /opt/homebrew。
Go 未检测到 安装完成后需要重新打开终端，或运行 exec zsh -l 刷新环境。
初学者建议：优先使用“方式一：Homebrew 自动安装”。它适合日后升级和卸载，也更容易配合开发环境管理。

方式一：Homebrew 自动安装

这是当前机器的推荐方式。脚本会检查 Homebrew，如果不存在则提示安装；随后安装 Go、Git 和常用 VS Code 插件，并输出 Go 版本和关键环境变量。

执行前注意：如果你已经通过官方 pkg 安装过 Go，建议先运行 go version 和 which go 看看来源。初学阶段最好只保留一种安装方式，避免 PATH 混乱。 
cat > /tmp/setup-go-macos.sh <<'SH'
#!/usr/bin/env bash
set -euo pipefail

echo "==> macOS Go installer"
echo "OS: $(sw_vers -productName) $(sw_vers -productVersion) ($(sw_vers -buildVersion))"
echo "CPU: $(uname -m)"

if ! command -v brew >/dev/null 2>&1; then
  echo "Homebrew 未安装。请先按官网安装 Homebrew: https://brew.sh/"
  exit 1
fi

if [[ -x /opt/homebrew/bin/brew ]]; then
  eval "$(/opt/homebrew/bin/brew shellenv)"
elif [[ -x /usr/local/bin/brew ]]; then
  eval "$(/usr/local/bin/brew shellenv)"
fi

echo "==> Updating Homebrew..."
brew update

echo "==> Installing Go and Git..."
brew install go git

echo "==> Ensuring GOPATH bin is in ~/.zshrc..."
touch "$HOME/.zshrc"
if ! grep -q 'export PATH="$PATH:$HOME/go/bin"' "$HOME/.zshrc"; then
  printf '\n# Go user installed tools\nexport PATH="$PATH:$HOME/go/bin"\n' >> "$HOME/.zshrc"
fi
export PATH="$PATH:$HOME/go/bin"

if command -v code >/dev/null 2>&1; then
  echo "==> Installing VS Code Go extension..."
  code --install-extension golang.go --force || true
fi

echo "==> Installed versions:"
go version
go env GOPATH GOROOT GOOS GOARCH GOPROXY
SH

bash /tmp/setup-go-macos.sh

如果最后输出类似 go version go1.26.3 darwin/amd64，说明安装成功。版本号会随着 Go 官方发布和 Homebrew 源更新而变化。

方式二：官方 pkg 安装

Go 官方 macOS 安装包会把 Go 安装到 /usr/local/go，并把 /usr/local/go/bin 写入 PATH。如果你不想使用 Homebrew，可以使用官方 pkg。

Mac 类型 应该下载的包 如何判断
Intel Mac macOS x86-64 pkg uname -m 输出 x86_64。
Apple Silicon Mac macOS ARM64 pkg uname -m 输出 arm64。
  1. 打开 Go 官方下载页。
  2. 根据上表选择 macOS 安装包。
  3. 双击 .pkg 文件，按安装器提示继续。
  4. 安装完成后关闭 Terminal，重新打开。
  5. 运行 go version 验证。
go version
which go
go env GOPATH GOROOT GOOS GOARCH
不要混装：如果你已经用 Homebrew 安装了 Go，不建议再安装官方 pkg。两者都能工作，但新手容易被 which go 和 PATH 顺序搞混。

安装 VS Code Go 插件

VS Code 安装官方 Go 插件后，会提供语法提示、跳转、格式化、调试和测试入口。第一次打开 Go 项目时，它可能提示安装 gopls、dlv 等工具，按提示安装即可。 

if command -v code >/dev/null 2>&1; then
  code --install-extension golang.go --force
else
  echo "未找到 code 命令。可以打开 VS Code，在扩展市场搜索 Go 并安装官方 Go 插件。"
fi

如果安装 Go 插件后仍然没有补全，可以手动安装语言服务： 

go install golang.org/x/tools/gopls@latest

可选：配置 Go 模块代理

Go 下载第三方依赖时会访问模块代理。如果下载很慢，可以配置代理。公司或团队有统一代理时，应优先使用团队配置。 

# 中国大陆网络常用配置
go env -w GOPROXY=https://goproxy.cn,direct

# 恢复 Go 官方默认代理
go env -w GOPROXY=https://proxy.golang.org,direct

# 查看当前配置
go env GOPROXY GOPATH GOROOT GOBIN

创建第一个 Go 项目

Go 现在以模块为基本单位。初学时可以把练习项目放到用户目录下，例如 $HOME/go-practice/hello-go。 

mkdir -p "$HOME/go-practice/hello-go"
cd "$HOME/go-practice/hello-go"

go mod init example.com/hello-go

cat > main.go <<'GO'
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go on macOS!")
}
GO

gofmt -w main.go
go run .

看到 Hello, Go on macOS! 就说明开发环境已经能正常编译和运行 Go 程序。

再加一个测试

Go 自带测试工具，初学者应该尽早习惯 go test。 

cat > add.go <<'GO'
package main

func Add(a int, b int) int {
	return a + b
}
GO

cat > add_test.go <<'GO'
package main

import "testing"

func TestAdd(t *testing.T) {
	got := Add(2, 3)
	want := 5
	if got != want {
		t.Fatalf("Add(2, 3) = %d, want %d", got, want)
	}
}
GO

gofmt -w add.go add_test.go
go test ./...

如果输出 ok，说明测试通过。

日常常用命令

命令 用途
go version 查看 Go 是否安装成功，以及当前版本。
which go 查看当前终端实际使用哪个 Go 命令，排查 Homebrew/pkg 混装很有用。
go env 查看 Go 环境变量，例如 GOPATH、GOROOT、GOPROXY。
go mod init example.com/app 初始化一个 Go 模块。
go run . 编译并运行当前目录的程序。
go test ./... 运行当前模块下所有测试。
go fmt ./... 格式化当前模块下的 Go 代码。
go mod tidy 整理依赖，添加缺失依赖并删除不再使用的依赖。
go install package@latest 安装 Go 编写的命令行工具到 $HOME/go/bin。

常见问题

Terminal 提示 command not found: go

如果刚安装完 Go，先关闭 Terminal 再重新打开。仍然失败时运行： 

echo "$PATH"
which go

# Homebrew 安装时，Intel Mac 常见路径
eval "$(/usr/local/bin/brew shellenv)"

# Apple Silicon Mac 常见路径
eval "$(/opt/homebrew/bin/brew shellenv)"

Homebrew 安装后版本不是最新

先更新 Homebrew 索引，再升级 Go： 

brew update
brew upgrade go
go version

VS Code 能打开文件，但没有补全和跳转

确认已安装官方 Go 插件，并允许它安装 gopls。也可以在终端运行： 

go install golang.org/x/tools/gopls@latest

GOROOT 和 GOPATH 要手动设置吗

初学者通常不需要手动设置。GOROOT 是 Go 安装目录；GOPATH 默认是 $HOME/go。现在 Go 项目主要依赖 go.mod 管理，不需要把项目放进 GOPATH。

卸载或升级

如果使用 Homebrew 安装： 

# 升级 Go
brew update
brew upgrade go

# 卸载 Go
brew uninstall go

如果使用官方 pkg 安装： 

# 删除官方 pkg 安装目录。执行前请确认你没有用 Homebrew 管理 Go。
sudo rm -rf /usr/local/go
谨慎删除：$HOME/go 里可能有你安装的工具、模块缓存和练习项目。卸载 Go 通常不需要删除这个目录，除非你明确知道里面没有要保留的内容。
