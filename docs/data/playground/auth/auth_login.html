POST /auth/login curl 验证报告

该接口接收手机号和短信验证码。验证码正确时，如果手机号尚未存在，会自动注册用户，并返回真实 JWT token 与 user_id。

Method: POST Path: /auth/login 验证时间：2026-06-08 15:17

接口信息

请求地址 http://localhost:8080/auth/login
请求体 {"phone":"13800000001","code":"短信接口返回的六位验证码"}
成功响应 返回 token 和 user_id。token 是后端用真实 JWT 库生成的 HS256 JWT。

测试 curl

BASE_URL="http://localhost:8080"
PHONE="13800000001"

SMS_RESPONSE=$(curl -sS -X POST "$BASE_URL/auth/sms" \
  -H "Content-Type: application/json" \
  -d "{\"phone\":\"$PHONE\"}")

CODE=$(printf "%s" "$SMS_RESPONSE" | node -e \
  'const fs=require("fs"); const data=JSON.parse(fs.readFileSync(0,"utf8")); process.stdout.write(data.code);')

curl -sS -X POST "$BASE_URL/auth/login" \
  -H "Content-Type: application/json" \
  -d "{\"phone\":\"$PHONE\",\"code\":\"$CODE\"}"

本轮验证命令

本轮使用 POST /auth/sms 返回的验证码 437260 继续登录。

BASE_URL="http://localhost:18080"

curl -sS -X POST "$BASE_URL/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800000001","code":"437260"}'
