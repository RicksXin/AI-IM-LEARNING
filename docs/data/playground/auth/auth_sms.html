POST /auth/sms curl 验证报告

该接口用于模拟发送短信验证码。playground 阶段直接返回六位随机验证码，方便前后端联调。

Method: POST Path: /auth/sms 验证时间：2026-06-08 15:17

接口信息

请求地址 http://localhost:8080/auth/sms
请求体 {"phone":"13800000001"}
成功响应 返回手机号和六位随机验证码。

测试 curl

BASE_URL="http://localhost:8080"

curl -sS -X POST "$BASE_URL/auth/sms" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800000001"}'

本轮验证命令

为避免占用常用端口，本轮用临时端口 18080 启动后端验证。

BASE_URL="http://localhost:18080"

curl -sS -X POST "$BASE_URL/auth/sms" \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800000001"}'

本轮实际结果

{
  "code": "437260",
  "phone": "13800000001"
}

验证通过：接口返回了六位数字验证码，并回显了请求手机号。

说明：验证码保存在后端内存中，服务重启后会失效，需要重新调用该接口。
