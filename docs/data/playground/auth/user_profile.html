GET /user/profile curl 验证报告

该接口需要请求头携带 JWT token。服务端从 token 中解析 user_id，并返回模拟用户资料；缺失或无效 token 返回 401。

Method: GET Path: /user/profile 验证时间：2026-06-08 15:17

接口信息

请求地址 http://localhost:8080/user/profile
请求头 Authorization: Bearer <token>
成功响应 返回 user_id、nickname、avatar、phone。
失败响应 token 缺失或无效时返回 401。

测试 curl：成功场景

BASE_URL="http://localhost:8080"
TOKEN="登录接口返回的 JWT"

curl -sS -X GET "$BASE_URL/user/profile" \
  -H "Authorization: Bearer $TOKEN"

本轮成功结果

本轮使用 POST /auth/login 返回的 JWT token 请求用户资料。

{
  "user_id": "u_000001",
  "nickname": "13800000001",
  "avatar": "https://example.com/avatars/u_000001.png",
  "phone": "13800000001"
}

验证通过：服务端从 JWT 中解析出 user_id，并返回了对应的模拟用户资料。

测试 curl：缺失 token

BASE_URL="http://localhost:8080"

curl -sS -i -X GET "$BASE_URL/user/profile"

本轮缺失 token 结果

HTTP_STATUS:401
{
  "error": "token is required"
}

测试 curl：无效 token

BASE_URL="http://localhost:8080"

curl -sS -i -X GET "$BASE_URL/user/profile" \
  -H "Authorization: Bearer invalid.jwt.token"

本轮无效 token 结果

HTTP_STATUS:401
{
  "error": "invalid token"
}

验证通过：缺失 token 和无效 token 都被拒绝，符合接口要求。
