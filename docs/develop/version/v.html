Beginner Backend Guide

第一个 Gin 后端接口：/v 系统版本信息

后端目录：server 框架：Gin 接口：GET /v 默认端口：8080

这个接口做什么

本次创建的是整个后端项目的第一个服务接口。启动服务后，访问 /v，后端会返回系统名称和版本号。 

{
  "name": "LearningAI IM Backend",
  "version": "0.1.0"
}

这个接口很小，但很重要。它可以用来确认后端是否启动成功，也方便前端、运维脚本或健康检查工具知道当前后端版本。

项目文件

文件 作用
server/go.mod Go 模块文件，记录项目名称和依赖。本项目使用 github.com/gin-gonic/gin。
server/main.go 服务入口。这里创建 Gin 路由、注册 /v 接口，并启动 HTTP 服务。
server/main_test.go 接口测试。它会模拟请求 /v，检查返回状态码和 JSON 字段是否正确。

第一次启动

先进入后端项目目录： 

cd D:\Developer\Project\Personal\LearningAI\server

第一次运行前，下载依赖： 

go mod tidy

启动服务： 

go run .

服务启动后，终端会打印类似下面的地址： 

server listening on 0.0.0.0:8080
version endpoint: http://localhost:8080/v
version endpoint: http://192.168.x.x:8080/v
怎么看：localhost 是本机访问地址；192.168.x.x 这种是局域网地址，同一网络下的手机或其他电脑可能也能访问。

访问接口

服务启动后，可以打开浏览器访问： 

http://localhost:8080/v

也可以在 PowerShell 里请求： 

Invoke-RestMethod http://localhost:8080/v

如果你安装了 curl，也可以这样： 

curl http://localhost:8080/v

修改端口

默认端口是 8080。如果 8080 被占用，可以临时换成 9090： 

$env:PORT = "9090"
go run .

访问地址也要跟着改： 

http://localhost:9090/v

运行测试

测试可以帮助你确认接口没有被改坏。进入 server 目录后运行： 

go test ./...

如果看到类似 ok learningai/server，说明测试通过。

代码说明

接口数据

main.go 里定义了两个常量： 

const (
    appName    = "LearningAI IM Backend"
    appVersion = "0.1.0"
)

以后如果要改系统名或版本号，可以先改这里。

注册路由

router.GET("/v", handleVersion)

这行表示：当浏览器或客户端请求 GET /v 时，Gin 会调用 handleVersion 函数处理。

返回 JSON

c.JSON(http.StatusOK, VersionResponse{
    Name:    appName,
    Version: appVersion,
})

http.StatusOK 是 HTTP 200，表示请求成功。后面的结构体会被 Gin 自动转换成 JSON。

常见问题

提示 go 不是内部或外部命令

说明当前电脑还没有安装 Go，或者终端没有加载 Go 的 PATH。可以先看安装文档：Windows 11 初学者 Go 环境安装指南。

端口被占用

如果看到 bind: Only one usage of each socket address 之类的错误，说明端口已经被其他程序占用。可以改用别的端口： 

$env:PORT = "9090"
go run .

局域网地址访问不了

先确认服务启动时打印了 0.0.0.0:8080，再检查 Windows 防火墙是否允许当前程序访问网络。初学阶段优先用 localhost 验证本机访问。

下一步建议

  1. 把 /v 当作后端是否可用的最小验证接口。
  2. 后续可以新增 /health 做健康检查，新增 /api 存放业务接口。
  3. 随着接口变多，再把 main.go 拆成 config、router、handler、service 等目录。
